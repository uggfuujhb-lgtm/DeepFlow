# الروتين

كل الأوقات بتوقيت الرياض وبنظام 12 ساعة. أوقات السوق في التوقيت الشتوي: الافتتاح 5:30 PM والإغلاق 12:00 AM.

| الروتين | الوقت | المسؤول | المخرج |
|---------|-------|---------|--------|
| ملخص الصباح | كل يوم **10:00 AM** | المدير + مكتب السوق | ملخص السوق + خطة اليوم |
| حزمة المحتوى | كل يوم تداول **11:00 AM** | المحتوى | مسودات + طلبات موافقة |
| النشر | كل يوم تداول **3:00 PM** | المحتوى | نشر المعتمد بس |
| ختام اليوم | كل يوم **12:15 AM** | المدير | تقرير اليوم |
| فحص الليل | كل يوم **3:00 AM** | المدير | فحص صحة اللوحة والملفات |
| ملخص المحاضرة | كل **أحد 8:00 PM** | الأكاديمية | ملخص مذاكرة للمالك |
| حزمة المراجعة | كل **ثلاثاء 10:00 AM** | الأكاديمية | مراجعة للطلاب (مسودة) |
| اجتماع الأسبوع | كل **سبت 11:00 AM** | المدير + كل الأقسام | تقرير الأسبوع + خطة الأسبوع |
| المراجعة الشهرية | أول **سبت** من كل شهر **12:00 PM** | المدير | تقرير الشهر + تقدّم الهدف |

---

## 1. ملخص الصباح، 10:00 AM
1. مكتب السوق يكتب `out/market/YYYY-MM-DD.md`.
2. المدير يقرأ اللوحة: وش متوقف، ووش ينتظر المالك، ووش موعده اليوم.
3. المدير يرسل للمالك:
   - **السوق اليوم** في 3 أسطر.
   - **ينتظرك** (عدد العناصر وأهمها).
   - **مهام اليوم** لكل قسم.
   - المواعيد المهمة (بيانات اقتصادية، محاضرة، إطلاق).

## 2. ختام اليوم، 12:15 AM (بعد إغلاق السوق)
- تقرير بالصيغة الخماسية: تم / الملفات / يحتاج المالك / متوقف / التالي.
- سطر واحد: هل السوق مشى على سيناريو الصباح؟ (للتعلّم ومادة محتوى بكرة).
- نقاط الخبرة اللي انمنحت اليوم.
- الأقسام كلها `idle` أو `off`.

## 3. اجتماع الأسبوع، السبت 11:00 AM
- الأرقام: متابعين وقناة وتسجيلات ودخل (من قسم النمو).
- وش اشتغل في المحتوى ووش ما اشتغل (أعلى 3 وأقل 3).
- الأكاديمية: محاضرة الاثنين الجاي جاهزة؟
- خطة الأسبوع: 3 أولويات بس.
- لوحة الشرف: مين ارتفع مستواه.

## 4. المراجعة الشهرية، أول سبت 12:00 PM
- **تقدّم هدف الـ100 ألف:** المحقّق، والمتبقي، والمطلوب شهرياً، وكم طالب نحتاج.
- مراجعة الأقسام: نضيف قسم أو ندمج أو نعدّل الأوصاف (والقرار للمالك).
- مراجعة القواعد والصلاحيات.
- مراجعة التكاليف (اشتراكات البيانات، الأدوات). أي تغيير = موافقة.

## 5. فحص الليل، 3:00 AM
- مهام `doing` ما تحدّثت من أكثر من 24 ساعة؟ تتحوّل `blocked` مع ملاحظة.
- عناصر `needs` قديمة من أكثر من 48 ساعة؟ تتصعّد في ملخص الصباح.
- ملفات `out/` اليوم موجودة ومطابقة لقوائم «خلص»؟
- هل فيه شي انشر بدون `approved`؟ (يُفترض صفر، وإذا لا يتصعّد فوراً).
- **فحص بس:** ما فيه أي فعل خارجي.
