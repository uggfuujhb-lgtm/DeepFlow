# موقع التسجيل: OptionLap

صفحة تسجيل في دورة الأوبشن فلو والأوردر فلو، مبنية على نظام تصميم OptionLap (الثيم الليلي).

- `index.html`: الصفحة (المنهج، وطريقة الدورة، والسعر، ونموذج التسجيل، والأسئلة، والدعم الفني @R166o).
- `api/register.js`: يستقبل طلب التسجيل ويرسله لمحادثتك الخاصة مع البوت على تلقرام. **ما يرسل للقناة العامة.**
- `assets/`: الأيقونة وصورة المشاركة.

## التشغيل على Vercel (بيد المالك)
1. في Vercel: **Add New → Project** واختر مستودع DeepFlow.
2. **Root Directory** = `site`.
3. **Environment Variables**:
   - `TELEGRAM_BOT_TOKEN` = توكن البوت.
   - `REGISTRATION_CHAT_ID` = رقم محادثتك الخاصة مع البوت. أرسل `/start` للبوت من حسابك، والفريق يطلّع لك الرقم.
4. **Deploy**. والدومين (مثل optionlap.com) يتربط من إعدادات المشروع بعد الشراء، والشراء قرار المالك.

> بدون المتغيّرين، الصفحة تشتغل بس النموذج يقول «التسجيل مو مفعّل» ويوجّه للدعم الفني.
